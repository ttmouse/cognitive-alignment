# 附录 C｜讨论质量自检

> 会议结束后（或过程中）对照以下问题自检，找出下一次可以改进的一个动作。

⬅️ [上一章](附录B-会后共同模型模板.md) ｜ [目录](00-阅读说明.md) ｜ [下一章](00-阅读说明.md) ➡️

---

- [ ] 参与者是否知道为什么开会、自己为什么参加？
- [ ] 最接近事实的人是否有机会在判断形成前完整表达？
- [ ] 白板或文档是否区分了原始表达、事实、判断和假设？
- [ ] 记录是否加入了表达者没有说出的意思？
- [ ] 模糊词是否补充了对象、范围、时间、证据和标准？
- [ ] 跑题问题是否被记录和分流，而不是被压制或无限展开？
- [ ] 讨论是否从问题转向了对个人能力、态度或动机的评价？
- [ ] 结论是否明确对应责任人、时间和验收标准？
- [ ] 没有达成的分歧是否被真实保留？
- [ ] 会后文档是否能让未参会者理解“为什么得出这个结论”？
