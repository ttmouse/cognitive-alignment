# 白板与会议记录模板

## 模板一：标准讨论白板

```text
┌──────────────────────────────────────────┐
│ 背景：                                   │
│ 目标：                                   │
│ 边界：                                   │
├──────────────────┬───────────────────────┤
│ 已确认事实       │ 待确认问题            │
│                  │                       │
├──────────────────┼───────────────────────┤
│ 判断 / 假设      │ 候选方案              │
│                  │                       │
├──────────────────┼───────────────────────┤
│ 决策与行动       │ 议题停车场            │
│                  │                       │
└──────────────────┴───────────────────────┘
```

## 模板二：忠实外化记录

```text
发言者原意：
【尽量保持原词，不增加新信息】

表达者确认：
- [ ] 无偏差
- [ ] 已修正

补充澄清：
- 对象：
- 范围：
- 场景：
- 时间：
- 标准：
- 证据：
```

## 模板四：对象建模

```text
对象名称：
定义：
唯一标识：
关键属性：
可能状态：

可执行动作：
与其他对象关系：

```

## 模板五：流程规则

```text
当【触发条件】发生时，
由【角色】
对【对象】
执行【动作】，
使对象从【状态 A】进入【状态 B】。

如果【异常条件】，
则【异常处理】。

必须记录【证据 / 审计信息】。
```
