# 认知对齐：复杂组织中的高质量讨论方法

> 从目标对齐、过程控制、忠实外化，到共同建模与行动闭环。

这个项目沉淀一套关于复杂组织如何建立共同认知的方法体系。

核心问题：为什么很多会议结束后，大家听到了同样的话，却没有形成同样的理解？

核心方法：

1. 讨论前：明确背景、目标、角色和边界。
2. 讨论中：控制信息、议题、时间和情绪秩序。
3. 认知对齐：先忠实外化，再共同澄清，最后结构化建模。
4. 行动闭环：将结论转化为责任、时间和可验证结果。

## 核心原则

> 先忠实还原，再共同澄清，最后形成判断。
